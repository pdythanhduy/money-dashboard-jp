# 日本人ユーザー向けプロモビデオ脚本（日本語版）

App Store Preview / Google Play 紹介動画 / YouTube 短尺動画用の脚本。`docs/screenshot-checklist.md` で定義されている 5 シーンの画像をそのまま使い、日本語ナレーション＋字幕で再構成。

**目標尺：** 30 秒（App Store Preview の上限）。各シーン約 5 秒 + イントロ／アウトロ各 2.5 秒。
**ターゲット：** 日本在住の外国人（特にベトナム人）+ 日本人読者にも違和感のない丁寧な日本語。
**音声：** 静かな BGM（著作権フリー、和楽器系または穏やかな piano）+ 女性ナレーター推奨（落ち着いた事務的トーン）。
**字幕：** 全シーンに日本語字幕を焼き込む。ナレーション無しでも内容が伝わるように。

スクリーンショットの撮影手順・シード値は [`screenshot-checklist.md`](screenshot-checklist.md) を参照。本ファイルは「同じ画像を使って日本語動画にする」ための音声・字幕レイヤーのみを定義。

## イントロ（0:00 – 0:02.5）

**画面：** Kakei アプリアイコン（白背景）→ アプリ起動アニメーション（Dashboard が表示される）。

**ナレーション（日本語）：**
> 日本で暮らすあなたの家計を、ひとつのアプリで。

**画面上テキスト（字幕）：**


## トーン・スタイル指針

| 要素 | 指針 |
|---|---|
| 敬語レベル | 「ます」「です」体。「だ・である」体は使わない。 |
| 数字表記 | 全角・半角混在を避ける。金額は半角 ¥ 記号 + カンマ区切り（¥40,000）。 |
| カタカナ語 | 「ダッシュボード」「カテゴリ」など定着語のみ。「アグリゲーター」「コンソリデート」のようなマーケ用語は避ける。 |
| 数値の誇張 | 「圧倒的な〇〇」「最高の〇〇」は使わない。実機能ベースで語る。 |
| プライバシー強調 | 「100%オフライン」「データは端末内に保存」を 1 回以上必ず登場させる。 |

## 法的・コンプライアンス注意

- 「税理士に代わって申告」「節税」「絶対正確」などの誇大表現は使わない。
- App Store Connect の動画レビューでは「価格」「販売中」などの誤解を招く字幕も NG。
- 実在の銀行・送金サービス（Wise / Remitly 等）のロゴは表示しない（商標利用）。
- 動画末尾に「アプリ内画面はイメージです。実際の数値は入力内容により異なります。」の小さい注意書きを 0.5 秒入れると安全。
